# Was This Article Helpful? - Find.co

## Installation:

### Manual Installation:

1. Download the plugin ZIP file from https://github.com/bajak1994/findco-task.
2. Log in to your WordPress Dashboard.
3. Navigate to "Plugins" -> "Add New."
4. Click on "Upload Plugin" and choose the downloaded ZIP file.
5. Activate the plugin.

## Usage:

1. **Voting:**
   - At the end of each single article, you will find the Yes and No buttons.
   - Click on either button to submit your vote.
   - After voting, the buttons will become inactive, and the results will be displayed.

2. **Viewing Results:**
   - Once you've voted, the average percentage result will be visible.
   - While editing the article from the admin area, the number of votes will be visible on the right side in "Voting Results" meta box.

## Troubleshooting:

1. **Conflict with Themes or Plugins:**
   - Disable other plugins or switch to a default WordPress theme to identify conflicts.

## Frequently Asked Questions (FAQs):

1. **Q: Can I move the voting system to a different location?**
   - A: Currently, the plugin supports placement at the end of single articles. Custom positions are not available.

2. **Q: How can I reset the votes for an article?**
   - A: There is no built-in reset feature. You can manually edit the database or contact support for assistance.

3. **Q: Is user data stored when using the Simple Voting System?**
   - A: Yes, the plugin stores minimal data to prevent duplicate votes on the same article. The stored information is used solely for this purpose and is not shared or used for any other tracking purposes.
